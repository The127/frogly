# frogly

[![ci](https://github.com/The127/frogly/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/The127/frogly/actions/workflows/ci.yml)
[![coverage](https://codecov.io/gh/The127/frogly/graph/badge.svg)](https://app.codecov.io/gh/The127/frogly)

frogly is a task planner for self-organized teams. You host it yourself.

Many planning tools are built for the people who watch the work. They ask
for fields, reports and workflows that slow down the people who do it.
frogly keeps planning light. You write down an idea in one line. Ideas that
enough people want become tickets on a simple board, and the rest fade on
their own.

## Status

frogly is at an early stage. So far you can log in, create projects and see the ones you're a member
of.
[Running frogly](CONTRIBUTING.md#running-frogly) says how to try it. The
[vision](docs/vision.md) describes what frogly is going to be, and the
[design demo](docs/design/) shows how it could look.
